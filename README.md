# MoynoviuJARVIS_bot 🤖

Персональный ИИ-ассистент Джарвис на базе микросервисов **NVIDIA NIM** с поддержкой анализа финансовых отчетов и расчета экономики магазинов на маркетплейсах.

## 📌 Описание:
- **нвидия ( Георгий )** — интеграция с облачными нейросетями через NVIDIA NIM API (`nvidia/nemotron-3.5-bolt-e4b`).
- **привет** — умный диалоговый режим с сохранением контекста беседы и постоянными кнопками меню.
- **посчитай экономику магазина на вайлдберисе** — автоматический глубокий анализ пакетов финансовых отчетов (.xlsx, .csv):
  - Выручка и фактические продажи
  - Комиссии маркетплейса (КВВ) и логистика ПВЗ
  - Затраты на рекламу по кампаниям, расчет ДРР и конверсий
  - Чистый доход к перечислению и практические рекомендации для бизнеса

## 📁 Поддерживаемые форматы файлов:
- **Excel:** `.xlsx`, `.xls` (автоматический разбор листов, вычисление сумм и финансовых итогов)
- **CSV / TSV:** `.csv`, `.tsv` (автоопределение кодировок UTF-8 и CP1251)
- **PDF:** `.pdf` (извлечение текста со страниц)
- **Word:** `.docx` (текст и таблицы)
- **Текстовые файлы:** `.txt`, `.json`, `.log`

## 🚀 Быстрый запуск:
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/akininanatasha-creator/-MoynoviuJARVIS_bot.git
   cd -MoynoviuJARVIS_bot
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `api_key.txt` с вашим ключом NVIDIA NIM (`nvapi-...`).
4. Создайте файл `bot_token.txt` с токеном Telegram-бота.
5. Запустите бота:
   ```bash
   python telegram_bot.py
   ```
